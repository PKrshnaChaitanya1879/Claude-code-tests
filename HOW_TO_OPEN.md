# How to open the game

The Unity project is being built by scheduled runs. Until `PROGRESS.md` shows M1 ticked, there is nothing to open yet. The browser prototype is the playable reference meanwhile.

When it's ready:

1. **Download.** Get the branch as a ZIP: https://github.com/PKrshnaChaitanya1879/claude-code-tests/archive/refs/heads/twenty-thousand-leagues.zip
2. **Unzip.** Unzip it somewhere short, e.g. `C:\Users\fumbl\TwentyThousandLeagues`.
3. **Add the project.** In Unity Hub, choose **Add → Add project from disk** and pick the `Unity\TwentyThousandLeagues` folder inside it. Open it with Unity 6.
4. **First open.** The first open builds the scenes automatically and takes a few minutes. If it doesn't, use the menu **Verne → Build Everything**.
5. **Play.** Open `Assets/Scenes/Title.unity` and press Play.
